Digitaalinen mittaristo

Tekijä: Pedro Virmanen

Ohjelma avaa toimivan mittariston, jota voi simuloida näppäimistöllä.

Sisältää:
Nopeusmittari (palkki ja luku)
Kierrosmittari (palkki ja luku)
Polttoainemittari
Lämpötilamittari
Vikavalot
Vaihteisto 1-6

Näppäimet:
W = Kiihdytys
S = Jarru
E = Vaihde ylös
Q = Vaihde alas

"main.cpp" sisältää lähdekoodin.
Toimiva .exe-tiedosto löytyy "build" kansiosta.
Ohjelman kääntäminen terminalissa: ./build/digidash.exe
